Simulador de Centrifugación

Objetivo

Este simulador permite visualizar el proceso de separación sólido-líquido mediante centrifugación utilizando realidad aumentada.

Variables modificables

• Velocidad del rotor (RPM)
• Radio efectivo
• Diferencia de densidades
• Tamaño de partícula
• Viscosidad del fluido

Parámetros calculados

• Velocidad angular
• Factor G
• Fuerza centrífuga
• Velocidad de sedimentación
